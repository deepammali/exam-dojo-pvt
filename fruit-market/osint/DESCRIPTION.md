**Objective:** Recover the flag that a company's web server has left exposed, and submit it.

1. Run `/challenge/run`. Your shell moves into the challenge network as host `10.0.0.1`. Type `exit` to leave it.
2. The host `10.0.0.2` serves a company website. Information has been left exposed on the site.
3. Investigate the site and recover the flag from it.

**Objective:** Answer every question about a Mandatory Access Control system correctly.

1. Run `/challenge/run`. It prints the security levels (highest first) and the categories of a Bell–LaPadula system.
2. Answer 5 questions, one after another. Each asks whether a subject with a given level and set of categories may **read** or **write** an object with a given level and set of categories. Answer `yes` or `no`.
3. You have **360 seconds** for all 5. One wrong answer ends the attempt; run it again to restart.

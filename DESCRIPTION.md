This is the Lab Internal Exam for Semester-I

Time limit: 1 Hour

Instructions:
1. **Before you start any challenge**, open this dojo's **Course** page, go to **Identity**, enter your **Reg. Number** exactly (format `26-08-01`) and save it. Marks are only given if you enter your roll number.
2. **To start a challenge:**
   1. Open the **Challenges** module, click a challenge to expand it, and click **Start**.
   2. Open the **Terminal** from the top bar. It connects to that challenge's machine.
   3. Run `/challenge/run` in the terminal and follow the challenge's description.
   4. The flag looks like `pwn.college{...}`. Paste it into the challenge's flag box and click **Submit**.

   Only one challenge runs at a time. Clicking **Start** on another challenge replaces the current one. Clicking **Start** again on the same challenge resets it.
3. Always take screenshot, put in word document and prepare report simultaneously to save time.
